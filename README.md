# Void Crew Samples Project

This repository contains samples to help you get started with modding Void Crew. The repository includes:
- A sample HDRP Unity Project with asset samples and the [Void Crew Common Library](https://github.com/HutlihutGames/void_crew_common)
- A sample pre-compiled mod that can copied and updated to upload custom asset bundles created with Unity, without having to write and compile any of your own code.
